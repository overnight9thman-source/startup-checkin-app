# 创业规划打卡APP

这是一个手机优先的 PWA 打卡工具，用来每天快速确认自己有没有做真正推动创业的行动。

它只记录6件事：

- 今天是否发布内容
- 今天是否增加业务资产
- 今天是否开发客户
- 今天刷短视频多久
- 今天是否运动
- 今天是否产生可见成果

保存后，记录会存在当前浏览器的 `localStorage` 里。当天重复保存会覆盖当天记录。页面底部会显示最近7天记录。

## 怎么打开使用

在电脑上，直接双击 `index.html` 打开即可。

在手机上，建议把整个文件夹放到一个可以被手机浏览器访问的位置，例如本地服务器、NAS、网盘网页服务或手机本机文件服务。用浏览器打开 `index.html` 后即可填写。

如果要完整使用 PWA 的离线缓存和添加到主屏幕功能，建议通过 `http://`、`https://` 或 `localhost` 访问，而不是直接用文件路径打开。

## 为什么看不到“安装应用”

如果你是直接双击 `index.html`，浏览器地址栏通常是 `file://`，这种方式可以使用打卡功能，但很多浏览器不会把它识别成可安装 PWA。

想看到“安装应用”或更完整的“添加到主屏幕”，需要满足这些条件：

- 页面通过 `https://` 或同一台设备上的 `localhost` 打开。
- 浏览器能读取 `manifest.json`。
- 浏览器能注册 `sw.js`。
- `manifest.json` 里有 192x192 和 512x512 图标。

电脑本地测试可以在当前文件夹运行：

```bash
python -m http.server 8080
```

然后用浏览器打开：

```text
http://localhost:8080
```

手机上最稳定的方式是把这个文件夹部署到一个 HTTPS 地址，例如 GitHub Pages、Netlify、Cloudflare Pages，或放到支持 HTTPS 的私有网页服务里。

## 安卓如何添加到主屏幕

1. 用 Chrome 打开这个工具页面。
2. 点击右上角菜单。
3. 选择“添加到主屏幕”或“安装应用”。
4. 确认后，桌面会出现“创业打卡”图标。

如果没有这个选项，先确认不是用 `file://` 打开的，也不是用普通局域网 `http://电脑IP:端口` 打开的。安卓 Chrome 对完整 PWA 安装通常要求 HTTPS，`localhost` 是例外。

## iPhone Safari 如何添加到主屏幕

1. 用 Safari 打开这个工具页面。
2. 点击底部分享按钮。
3. 选择“添加到主屏幕”。
4. 点击“添加”。

iPhone 请使用 Safari。iOS 上的 Chrome 菜单通常不会提供 Safari 那套“添加到主屏幕”入口。

## 每天什么时候填写

建议每天晚上收工前填写，时间控制在30秒内。

不要等到情绪很好时再填，也不要写长篇总结。这个工具只负责回答一个问题：今天有没有行动。

## 为什么只记录行动

创业早期最容易被想法、焦虑和计划消耗掉。想法本身不会带来客户、现金流和可见成果。

所以第一版不做登录、云同步、图表、月报和目标管理，只保留最小行动记录。每天能坚持填，才有后续优化的价值。

页面底部那句话就是使用原则：

只记录行动，不记录幻想。
